# Historial de versiones de Project Hub

Project Hub utiliza versionado semántico `MAJOR.MINOR.PATCH`.

## 0.1.0 — 07/08/2026

- Primera versión funcional del panel central de proyectos.
- Añade resumen con métricas, proyectos prioritarios y próximas tareas.
- Incluye CRUD local de proyectos con estado, prioridad, versión, tecnologías y enlaces.
- Añade gestión de tareas por proyecto y control de completadas.
- Incorpora búsqueda, filtros, ordenación y vistas responsive.
- Permite exportar, importar y restablecer los datos.
- Guarda la información en `localStorage` y deja preparada la estructura para Supabase.
